# SillyTavern 历代人生管理器

面向“死亡后换入同一世界另一具真实身体”的长篇 SillyTavern/MVU 玩法。插件负责查看当前身体、管理待确认人物卡，并把已经由预设生成的上一世归档草稿安全写入同一本现有世界书。

## 安装

在 SillyTavern 中打开：

`扩展 → 安装扩展`

粘贴仓库地址：

`https://github.com/jiangshuyu132-cloud/SillyTavern-LegacyLifeManager`

“分支或标签名”留空，选择“只给我安装”即可。

## 主要功能

- 查看 `stat_data.主角` 的当前身体、身份、属性、技能和状态。
- 兼容尚未建立 `主角.载体档案` 的旧聊天：从旧版主角字段、世界地点、生命值和状态效果显示现有资料，不修改原变量。
- 查看换身阶段、死亡信息、候选人物卡与归档状态。
- 手动选择某一条 AI 回复中的 `<char_info>`、人物卡或 JSON/YAML 人物卡；不会自动猜“最新回复”。
- 只把所选内容写入 `待确认人物卡`，不会自动接管身体。
- “填入确认换身”只把精确口令放进输入框，不会替玩家发送。
- 把 `待归档人生词条` 追加到所选的现有世界书，不创建第二本世界书。
- 相同词条自动去重；同名异文立即停止，不覆盖旧记录。
- 世界书保存并从后端回读成功后，才把状态改为“已写入世界书”并清空临时草稿。
- 对新旧身体完全相同的人格、感情、知识语言、技能和属性显示继承警告，不擅自修改。
- 导出当前身体、历代人生词条和完整聊天原文备份。

## 使用流程

1. 当前身体真正死亡后，确认 `换身状态.阶段` 已进入“等待换身”。
2. 让 AI 生成候选人物卡。
3. 在扩展的“换身候选”页选择那一条 AI 回复，预览后导入。
4. 点击“填入‘确认换身’”，核对后由你亲自发送。
5. 预设完成变量原子替换并生成 `待归档人生词条`。
6. 点击“归档上一世到世界书”。

## 数据与安全边界

- 插件不修改角色卡、预设或无关世界书词条。
- 当前身体仍以 `stat_data.主角` 为唯一事实来源。
- 完整聊天原文只进入你主动下载的备份，不注入模型。
- 普通 AI 回复不能直接新增世界书词条；只有本插件的明确按钮操作会写入。
- 建议换身前先导出备份。

## 兼容性

需要当前 SillyTavern 的 `SillyTavern.getContext()` 公共接口。读取和写入 MVU 时优先使用酒馆助手提供给扩展的 `TavernHelper.getVariables/updateVariablesWith`，其次使用 `Mvu.getMvuData/replaceMvuData`，并为旧版接口及常见消息变量结构保留兼容回退。
